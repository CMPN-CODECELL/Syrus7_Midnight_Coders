## Setup before Creating developer account 

1. Press `Win + R` to open the Run dialog.
2. Paste the following command (adjusting the Chrome executable path if necessary):

chrome.exe --user-data-dir="C://Chrome dev session" --ignore-certificate-errors --disable-web-security

3. A warning banner stating "You are using an unsupported command-line flag" will appear at the top. Open only the local development environment (`dev-carbon`) in this window. Do not log into personal accounts or open external sites.
