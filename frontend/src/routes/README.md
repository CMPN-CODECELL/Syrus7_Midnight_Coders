# TradeMint Frontend Application Routes

This directory utilizes **TanStack Router** file-based routing. Every route file maps directly to a deterministic application path.

---

## 🗺️ Route Map

| File | URL Route | Description |
| :--- | :--- | :--- |
| `__root.tsx` | App Shell | Global root wrapper providing Theme, Toast, and TanStack Query providers |
| `_app.tsx` | Layout Shell | Authenticated layout containing the top navigation bar, broker connectivity badge, and quick action bar (Email P&L trigger) |
| `index.tsx` | `/` | Root entry point (redirects to `/dashboard` or `/login`) |
| `login.tsx` | `/login` | User authentication screen with demo account quick-fill |
| `signup.tsx` | `/signup` | User registration screen |
| `connect.tsx` | `/connect` | 021 Broker credentials linking and status verification |
| `_app.dashboard.tsx` | `/dashboard` | Executive Trading Dashboard with portfolio metrics, P&L after friction, live candlestick charts, and Email Statement trigger |
| `_app.strategies.tsx` | `/strategies` | Strategy Studio displaying active algorithms, live P&L, square-off actions, and parameter tuning |
| `_app.strategies._id.tsx` | `/strategies/:id` | Individual strategy telemetry, execution log, and chart analysis |
| `_app.orders.tsx` | `/orders` | Real-time order book with lifecycle status chips and SEBI Rule 15 Digital Contract Notes |
| `_app.positions.tsx` | `/positions` | Isolated strategy position ledgers and opposing trade matrix |
| `_app.markets.tsx` | `/markets` | Real-time ticker feeds, market depth, and bid/ask spreads |
| `_app.risk-controls.tsx` | `/risk-controls` | Level 3 Risk Firewall, Multi-Scope Kill Switch modal, Auto-Trip Rules, and Interactive Chaos Lab |
| `_app.settings.tsx` | `/settings` | Account configuration, broker API settings, and Razorpay 3-Tier subscription manager |

---

## ⚠️ Notes & Conventions
- `routeTree.gen.ts` is automatically generated by TanStack Router during development and build. Do not modify it manually.
- The `_app` prefix signifies layout nesting; routes sharing the `_app.` prefix inherit the shared navigation shell rendered through `<Outlet />`.
